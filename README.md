## About

I work at the intersection of **data science, artificial intelligence, and software engineering**. I enjoy turning complex ideas into useful products—whether that means preparing reliable data, training a model, or shaping a clear and maintainable user experience.

My approach is practical: understand the problem, build deliberately, and keep improving the result.

## Focus

- Data analysis, machine learning, and intelligent applications
- Full-stack development and API-driven products
- Mobile development with Flutter
- Clear architecture, useful interfaces, and maintainable code
