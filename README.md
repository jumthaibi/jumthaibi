## About

I work at the intersection of data science, machine learning, and software engineering — training models, shaping data pipelines, and building the applications that put them to use. My background spans analysis-first languages like Python and R through to full-stack and mobile development, and I like moving fluidly between the two: the modeling side and the shipping side.

I care about writing code that's clean enough to hand off and systems that are simple enough to actually maintain.
